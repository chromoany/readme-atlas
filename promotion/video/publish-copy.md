# 发布文案

## 标题

推荐一个写 README 的开源 Skill：README Atlas

## 简介

新建、改写、审查、翻译，排版也一起整理。README Atlas 参考了 200 个项目的 README，根据仓库实际内容组织介绍、命令和首次使用示例。

准备开源一个项目，或者想给旧 README 补内容、改排版，可以拿自己的仓库试试。

项目地址：https://github.com/chromoany/readme-atlas

#开源项目 #README #Codex #AgentSkills #开发工具

## 交付文件

- `readme-atlas-promo-9x16.mp4`：竖屏成片。
- `poster.jpg`：视频封面。
- `subtitles.srt`：独立字幕；成片也已烧录字幕。
- `preview.html`：本地播放页。
- `storyboard.md`：分镜与配音文本。

配音使用本机中文合成语音，背景配乐为脚本原创合成。画面来自仓库事实、排版示意和日志示例运行记录，没有引用第三方视频、音乐或项目截图。
